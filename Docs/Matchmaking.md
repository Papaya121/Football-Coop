# Матчмейкинг Mirror

## Архитектура

- Один процесс Mirror принимает все клиентские подключения через KCP (UDP, порт `7777`).
- `FootballMatchmakingQueue` объединяет ожидающих клиентов попарно.
- Для каждой пары сервер динамически загружает отдельный экземпляр `Gameplay` в режиме `LocalPhysicsMode.Physics3D`.
- `FootballNetworkMatchScene` симулирует физику каждого экземпляра независимо.
- `SceneInterestManagement` отправляет клиенту только объекты его физической сцены. Объекты других матчей отсутствуют в памяти клиента.
- Движение, мяч, голы, счёт и таймер авторитетны на сервере. Клиент отправляет только нормализованный ввод и запросы действий.
- Клиент подтверждает загрузку сцены. Сервер создаёт игроков и мяч только после подтверждения от обоих участников.

## Жизненный цикл матча

- После полной загрузки `Gameplay` оба клиента отправляют `SceneReady`. Только после двух подтверждений сервер создаёт сетевые объекты и запускает общий обратный отсчёт.
- До окончания обратного отсчёта и во время паузы после гола сервер не принимает игровой ввод.
- Кнопка `GiveUp Button` во время матча сдаёт игру: вышедший клиент возвращается в меню, оставшийся получает победу.
- После обычного завершения оба клиента видят персональный результат. По умолчанию через 10 секунд сервер возвращает их в меню; значение задаётся полем `Result Presentation Seconds` у `FootballNetworkManager`.
- В завершённом матче подпись кнопки меняется с `Сдаться` на `Выйти`, позволяя не ждать автоматического возврата.

## Запуск

1. Соберите отдельный Dedicated Server или headless build, начиная со сцены `Menu`.
2. Запустите сервер. В headless-режиме он стартует автоматически.
3. Запустите два или больше клиентских экземпляра и нажмите `Игра по сети` → `Поиск матча`.

По умолчанию клиент подключается к `localhost:7777`. Адрес можно изменить в `FootballNetworkManager` на объекте `[Networking]` сцены `Menu` или передать при запуске:

```text
-networkAddress 203.0.113.10 -port 7777
```

Серверный порт также можно переопределить аргументом `-port`.

### Сервер внутри Editor

Для локальной разработки отдельный server build не требуется:

- `Football → Networking → Start Silent Server Now` — сразу запускает Play Mode как `Server Only`.
- `Football → Networking → Editor Runs As Silent Server` — переключатель режима для обычной кнопки Play.

Сервер работает без HUD на том же порту `7777`. Снимите переключатель `Editor Runs As Silent Server`, чтобы следующий Play Mode снова запускался как обычный клиент или локальная игра. Настройка хранится в `EditorPrefs` и не попадает в build.

## Расширение

- Правила формирования пар изолированы в `FootballMatchmakingQueue`.
- Жизненный цикл одного матча находится в `FootballServerMatch`.
- Транспорт, очередь и загрузку сцен координирует `FootballNetworkManager`.
- Ссылки конкретной сцены и отображение сетевого состояния инкапсулированы в `FootballNetworkMatchScene`.
- Сетевые сообщения собраны в `FootballNetworkMessages`.

После структурных изменений `Player.prefab`, `Ball.prefab` или `Gameplay.unity` запустите `Football → Networking → Configure Matchmaking`. Команда обновит только сетевые копии prefab'ов и необходимые сетевые компоненты сцен.
